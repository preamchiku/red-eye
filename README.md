# red-eye
RED EYE is a free, private, offline-ready browser video editor &amp; auto-caption PWA for Reels. Features Whisper Turbo subtitles in English, Kannada, Hindi, Tamil, Telugu, Kanglish &amp; Hinglish, 36 styles, per-box sizing/position, AI voice enhancer with 0-100% blend, multi-track timeline, and MP4/SRT/TXT export.
