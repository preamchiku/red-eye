Media

Import videos, music, voiceovers and pictures — each video goes to the end of the main lane; drag anything from the library onto a lane to place it exactly. Drag a clip to move it, drag its edges to trim. Ctrl/Cmd+B splits at the playhead, Q/W delete left/right, Backspace deletes (Ctrl/Cmd+Z undoes). The selected clip's settings — transform, crop, effects, speed, sound, keyframes — are in the Inspector on the rightunder the Video tab of this sheet. Every key can be changed: Ctrl/Cmd+,. Subtitles are on the Subtitles page.

Auto subtitles
Noisy video? Clean the voice in Audio first, then make subtitles. Speech models download only when selected and stay cached. Turbo uses multilingual Whisper large-v3-turbo for fast, high-accuracy captions across all languages. Check names and captions before export.
GPU Server (Optional — WhisperX + Resemble)

Runs gpu-backend/server.py (tuned for 4 GB VRAM / 8–16 GB RAM). If off or unreachable, RED EYE automatically uses in-browser Whisper & DeepFilterNet3.

Timeline XML

Paste the folder containing your original video, audio and image files. The XML stores paths to media; the receiving editor may still ask you to relink. RED EYE cannot read your computer's absolute file paths automatically.

Imports clip timing, trims, audio and tracks where supported. RED EYE effects, animated captions, transitions and title layers may not transfer as editable effects. A folder path helps create matching media URLs but cannot guarantee automatic relinking.
