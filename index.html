Install

Install RED EYE as an app

Install straight from Chrome on Windows and Mac, or Add to Home Screen on Android, iPhone and iPad. Always up to date, no sign-up.

Windows

Open in ChromeWindows 10/11

Open in Chrome (or Edge) and click the Install icon in the address bar → Install.

Mac

Open in ChromeApple Silicon & Intel

Open in Chrome (or Edge) on Mac and click the Install icon in the address bar → Install.

Android

Open in ChromeAndroid

In Android Chrome, tap ⋮ (top right) → Add to Home screen → Install.

iPhone & iPad

Open in SafariiOS & iPadOS 17+

In Safari tap Share → Add to Home Screen → Add. Opens like a native app.

⇩ Use it with no internet: Editor → Settings → Make RED EYE fully offline — one download of about 1.6 GB, then captions, voice typing, AI background and export all work offline. Open the offline pack →

System requirements

Minimum & recommended specs

Runs on everyday Windows and Mac laptops in your browser — and scales up smoothly with a 4 GB+ GPU.

Windows

Browser + Optional GPU Server

Minimum

  • OSWindows 10 (64-bit) or Windows 11
  • Processor4-core CPU (Intel Core i5 / AMD Ryzen 5)
  • Memory8 GB RAM
  • GraphicsIntegrated GPU (CPU/WASM) or 4 GB VRAM GPU
  • BrowserChrome 113+ or Edge 113+
  • Storage2 GB free space (model cache)

Recommended

  • OSWindows 11 (64-bit)
  • Processor6+ core CPU (Intel i5/i7 11th gen+ or Ryzen 5/7 5000+)
  • Memory16 GB RAM
  • Graphics4–8 GB VRAM NVIDIA RTX 30-series (RTX 3050/3060) or WebGPU GPU
  • BrowserLatest Chrome or Edge (WebGPU on)
  • Storage4 GB+ free SSD space

Mac

Apple Silicon & Intel

Minimum

  • OSmacOS 13 Ventura or newer
  • ProcessorApple M1 or quad-core Intel Core i5
  • Memory8 GB unified memory / RAM
  • GraphicsApple M1 GPU or Metal-capable GPU
  • BrowserChrome 113+, Edge 113+, or Safari 17+
  • Storage2 GB free space (model cache)

Recommended

  • OSmacOS 14 Sonoma or macOS 15 Sequoia
  • ProcessorApple Silicon M1 / M2 / M3 / M4
  • Memory16 GB unified memory or more
  • GraphicsApple Silicon GPU with WebGPU
  • BrowserLatest Chrome or Edge (fastest WebGPU & export)
  • Storage4 GB+ free SSD space

Tip: On 8 GB RAM or 4 GB VRAM devices, use Better or Turbo subtitle quality (or run the included gpu-backend/server.py in automatic Low-VRAM mode).
